**SyntaRay** is a minimalist code visualization tool with professional layout controls. Transform your raw code snippets into high-quality snapshots with precision.

### Key Features

- **Theming** — Switch between elegant Light and Dark modes.
- **Custom Backdrops** — Upload images or use gradients as your background.
- **Precision Layout** — Control width, height, frame dimensions, and padding.
- **Typography** — Custom line spacing, character spacing, and font uploads.
- **Window Styles** — Choose between macOS, Windows, or Minimal window decorations.
- **Instant Highlighting** — Real-time syntax highlighting powered by Shiki.
- **Persistence** — Settings are remembered locally using Zustand.

### Tech Stack

- **Core:** Next.js
- **Styling:** Tailwind CSS
- **State:** Zustand
- **Syntax:** Shiki
- **Icons:** Lucide React

### Quick Start

```bash
# Clone the repository
git clone https://github.com/ayazdoruck/syntaray.git

# Install dependencies
npm install

# Start development server
npm run dev
```
