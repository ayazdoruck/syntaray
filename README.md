**SyntaRay** is a high-performance, aesthetically driven code visualization tool designed for developers who value minimalism and precision. Transform your raw code snippets into professional, social-media-ready snapshots with just a few clicks.

### ✨ Key Features

-   🎨 **Dynamic Theming** — Seamlessly switch between elegant Light and Dark modes.
-   🖼️ **Custom Wallpapers** — Upload any high-res image as your background with local processing.
-   📐 **Advanced Layout** — Full control over Editor width/height, Frame dimensions, and Padding.
-   🔡 **Typography Freedom** — Custom line spacing, character spacing, and font uploads.
-   🪟 **Window Styles** — Choose between macOS, Windows, Gray, or Outline window decorations.
-   ⚡ **Instant Preview** — Real-time syntax highlighting powered by Shiki.
-   💾 **Session Persistence** — Your settings are remembered locally, always ready where you left off.

### 🛠️ Tech Stack

-   **Core:** [Next.js 15+](https://nextjs.org/) (React)
-   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
-   **State:** [Zustand](https://zustand-demo.pmnd.rs/) with Persistence middleware
-   **Syntax:** [Shiki](https://shiki.matsu.io/)
-   **Icons:** [Lucide React](https://lucide.dev/)

### 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/ayazdoruck/syntaray.git

# Install dependencies
npm install

# Start development server
npm run dev
```
